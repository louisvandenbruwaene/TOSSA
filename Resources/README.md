# Resources

## `art_manifest.json`

The single source of truth for which visual elements are sprites and which are still drawn by
code. `Game.gd` never names a PNG; it asks the bank for a **seam key** and takes whatever it
gets. Adding a line here promotes an element from procedural to sprite; deleting the line
demotes it back, with no code change either way.

```json
"prop/ball": { "path": "res://Assets/Props/ball.png", "pivot": [0.5, 0.5], "scale": 1.0 }
```

| Field | Meaning |
|---|---|
| `path` | any `res://` texture. Missing file = one warning, then procedural fallback, so a key can be reserved before the art exists |
| `pivot` | normalized. `[0.5,0.5]` centre (default), `[0.5,1.0]` pins the bottom edge to the draw position |
| `scale` | optional multiplier, for art authored bigger or smaller than its slot |

Keys beginning with `_` are documentation and are skipped by the loader.

**Ships with every key commented out and none registered**, so a default run of this branch is
the same picture `main` draws. That is deliberate: the branch should stay shippable at every
point of the remaster, not only at the end.

## `art_manifest.placeholder.json`

Generated by `scripts/gen_placeholders.gd`; registers all 31 placeholders at once. Never
loaded unless you ask for it:

```
godot --audio-driver Dummy -- --artmanifest res://Resources/art_manifest.placeholder.json
```

## Finding the keys

Don't maintain a list by hand - it will go stale. Run any screen with `--artreport` and it
prints every key that screen actually reached, each marked `[sprite]` or `[proc]`. That list
comes from the code, so it is correct by construction.
