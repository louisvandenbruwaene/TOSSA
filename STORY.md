# JUGGLE: Story (removed)

**As of 2026-07-11 the game has no story.** Louis chose to cut the narrative
entirely and make JUGGLE a pure, Balatro-style climb: six venues to conquer,
each with its own record to beat, and no cutscenes or characters.

Everything this document used to describe (the mentor Bruna, the rival Silvio,
the protagonist Milo, the ten-venue dramatic arc, the endgame beats) has been
deleted from the game. The cutscene engine, the character art, and the story
triggers are all gone from `Game.gd`. A new game now opens straight into the
hands-on tutorial and then the day hub. The win is mechanical: set a record at
the top stage (the World Arena) and the climb is complete, which shows a short
victory screen once, after which the career plays on.

The original story treatment is preserved in git history if it is ever wanted
again. It is intentionally not reproduced here, so this file cannot be mistaken
for a description of the current game.

See GDD.md for the current design and README.md for how the numbers work.
