# Downloading and playing JUGGLE

The actual game builds are attached to the [GitHub Releases page](https://github.com/louisvandenbruwaene/JUGGLE/releases)
rather than committed into this repo — that keeps every `git clone`/`git pull` fast
instead of dragging ~150MB of binaries through the whole project history.

Open the folder for your platform below for the direct download link and the
steps to get past the OS's "unknown developer" warnings (the app isn't
notarized/code-signed with a paid Apple/Microsoft certificate, so first-run
security prompts are expected):

- [macOS](macOS/README.md)
- [Windows](Windows/README.md)
- [Linux](Linux/README.md)

Latest version: **v0.1.0**. When a new build is exported, bump the version in
each platform README and cut a new release with the same tag name.
