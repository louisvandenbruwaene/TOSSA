# TOSSA — macOS

**[Download TOSSA-macOS.zip](https://github.com/louisvandenbruwaene/TOSSA/releases/download/v0.3.0/TOSSA-macOS.zip)**

1. Unzip it and drag `TOSSA.app` wherever you like (e.g. Applications).
2. It's ad-hoc signed but not notarized, so Gatekeeper will refuse a normal
   double-click the first time. Instead: right-click (or Control-click)
   `TOSSA.app` → **Open** → confirm **Open** in the dialog. You only need to
   do this once; after that it launches normally.
3. If macOS still blocks it, go to **System Settings → Privacy & Security**
   and click **Open Anyway** next to the TOSSA warning.

Requires Apple Silicon or Intel Mac (universal binary), macOS 10.13+.
