# JUGGLE — Linux

**[Download JUGGLE-Linux.zip](https://github.com/louisvandenbruwaene/JUGGLE/releases/download/v0.1.0/JUGGLE-Linux.zip)**

1. Unzip it — this gives you `JUGGLE.x86_64` and `JUGGLE.pck`. Keep them in
   the same folder; the executable loads the `.pck` next to itself at
   runtime.
2. Mark the binary executable and run it:
   ```
   chmod +x JUGGLE.x86_64
   ./JUGGLE.x86_64
   ```

Requires 64-bit Linux with standard desktop libraries (X11/Wayland, ALSA/Pulse).
