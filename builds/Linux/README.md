# TOSSA — Linux

**[Download TOSSA-Linux.zip](https://github.com/louisvandenbruwaene/TOSSA/releases/download/v0.3.0/TOSSA-Linux.zip)**

1. Unzip it — this gives you `TOSSA.x86_64` and `TOSSA.pck`. Keep them in
   the same folder; the executable loads the `.pck` next to itself at
   runtime.
2. Mark the binary executable and run it:
   ```
   chmod +x TOSSA.x86_64
   ./TOSSA.x86_64
   ```

Requires 64-bit Linux with standard desktop libraries (X11/Wayland, ALSA/Pulse).
