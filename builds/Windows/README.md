# JUGGLE — Windows

**[Download JUGGLE-Windows.zip](https://github.com/louisvandenbruwaene/JUGGLE/releases/download/v0.1.0/JUGGLE-Windows.zip)**

1. Unzip it anywhere and run `JUGGLE.exe`.
2. The build isn't signed with a paid code-signing certificate, so
   SmartScreen will show "Windows protected your PC" on first run. Click
   **More info** → **Run anyway**.

Requires 64-bit Windows 10+.
