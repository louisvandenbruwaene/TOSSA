# TOSSA — Windows

**[Download TOSSA-Windows.zip](https://github.com/louisvandenbruwaene/TOSSA/releases/download/v0.3.0/TOSSA-Windows.zip)**

1. Unzip it anywhere and run `TOSSA.exe`.
2. The build isn't signed with a paid code-signing certificate, so
   SmartScreen will show "Windows protected your PC" on first run. Click
   **More info** → **Run anyway**.

Requires 64-bit Windows 10+.
