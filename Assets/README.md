# Assets

Hand-authored artwork for the pixel-art remaster. **Nothing in here is referenced by name
from `Game.gd`** - the only thing that connects a file to the screen is a line in
`../Resources/art_manifest.json` keyed by an art seam key. That indirection is the point:
replacing a visual is a data edit, never a code edit.

## Authoring rules

| | |
|---|---|
| Canvas density | **320x180** - one art pixel is drawn as a 4x4 screen block (`ART_PIXEL = 4`) |
| Rule of thumb | author at **1/4** the size you want on screen: a 24px ball = 6px of art |
| Format | PNG, lossless, no mipmaps, nearest filter (project.godot's `[importer_defaults]` does this for you) |
| Colour | props, hands and gear are drawn through the game's colour as a **tint** - author those **white** |
| Never | upscale the current procedural art into a PNG. It is vector-smooth; scaling it produces a blurry sprite, not pixel art |

## Folders

| Folder | Seam keys | Notes |
|---|---|---|
| `Props/` | `prop/ball`, `prop/egg`, `prop/ring`, `prop/club`, `prop/knife`, `prop/torch`, `prop/chainsaw` | tinted and rotated; one file serves the stage, the shop card, the tutorial panel and the skills preview |
| `Characters/` | `char/head`, `char/head_back`, `char/hat_top`, `char/glasses`, `char/helmet`, `char/boot`, `char/hand_open`, `char/hand_closed`, `char/glove_open`, `char/glove_closed` | the figure's stance and proportions are settled - art is fitted to the size the game asks for, never the other way round |
| `Backgrounds/` | `bg/backyard`, `bg/street_corner`, `bg/small_theatre`, `bg/the_circus`, `bg/championship`, `bg/world_arena`, `bg/midnight_show` | full 320x180. **Do not paint the lighting in** - the spotlight, veil and footlights stay procedural because they react to the player |
| `UI/` | `ui/keycap`, `ui/card_skill`, `ui/card_trick`, `ui/gear_<id>` | stretched to a box the layout computed; proportion matters, absolute size does not |
| `Effects/` | `fx/flower_t0`, `fx/flower_t1`, `fx/flower_t2`, `fx/tomato` | flower tier is carried by petal count and colour - keep the three tiers visibly different |
| `Fonts/` | `pixel.ttf` / `.otf` / `.fnt` | picked up by filename, not by manifest. Present = it replaces Nunito everywhere, with antialiasing, subpixel positioning and hinting forced off |

## Current contents

Placeholders, generated by `scripts/gen_placeholders.gd`. They are white silhouettes with a
grey keyline and **one magenta pixel at the top-left corner** so they are impossible to
mistake for finished art. They are correctly sized, which is their real job: they state how
many pixels the final art gets.

They are **not** registered by default. To see them on screen:

```
godot --audio-driver Dummy -- --artmanifest res://Resources/art_manifest.placeholder.json
```

To find out which keys a given screen actually reaches, run it with `--artreport`.
